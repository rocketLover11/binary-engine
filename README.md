
# Binary Engine

## About

Binary engine is my game engine based on the concepts of Valve's Source Engine. This project is licensed under the GNU GPLv3 so anyone can use it. Currently it only runs on Windows as it uses Win32 APIs and DirectX 11 and relies on a Visual Studio solution.

## Build Instructions

### 1. Requirements

* A 64-bit Windows 10 or 11 machine

* Visual Studio 2026 with **Desktop development with C++** workload and v145 toolchain

* Git for Windows

### 2. Clone the repository

```batch
git clone https://github.com/rocketLover11/binary-engine.git
```

### 3. Open in Visual Studio

Navigate to the cloned repository in File Explorer and open `binary.slnx` in Visual Studio 2026

### 4. Build the engine

* Select `Debug` Or `Release`

* Right-click the solution and click `Build Solution`

### 5. Enjoy!

Use the bundled mod/game thingy or make your own!
